## Math

Inline math goes between single dollar signs: the gradient $\nabla f(x)$ points
uphill, so gradient descent steps the other way with learning rate $\eta$.

Display math goes between double dollar signs on their own lines:

$$
x_{t+1} = x_t - \eta \, \nabla f(x_t)
$$

For a quadratic $f(x) = \tfrac{1}{2} x^\top A x$, this converges when
$0 < \eta < 2 / \lambda_{\max}(A)$.[^1]

## Code

```python
import numpy as np

def gradient_descent(grad, x0, lr=0.1, steps=100):
    x = np.asarray(x0, dtype=float)
    for _ in range(steps):
        x = x - lr * grad(x)
    return x
```

Inline code looks like `np.linalg.eigvalsh(A)`.
