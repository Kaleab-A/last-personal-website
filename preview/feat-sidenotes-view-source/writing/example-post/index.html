Math

Inline math goes between single dollar signs: the gradient ∇f(x)\nabla f(x)∇f(x) points uphill, so gradient descent steps the other way with learning rate η\etaη.

Display math goes between double dollar signs on their own lines:

Notes in the margin

Asides that would interrupt a sentence can go in the margin.Like this. On a wide screen it sits beside the line it belongs to; on a phone, tap the number to open it. Use <Sidenote> for numbered notes and <MarginNote> for unnumbered ones.Good for credits, “see also” links, or a tiny diagram caption. Ordinary Markdown footnotes (like the one above) move into the margin on wide screens too.

Code

import numpy as np

def gradient_descent(grad, x0, lr=0.1, steps=100):
    x = np.asarray(x0, dtype=float)
    for _ in range(steps):
        x = x - lr * grad(x)
    return x
